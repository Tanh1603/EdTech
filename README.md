## 📖 Overview

This repository hosts a comprehensive EdTech system built on an advanced microservices architecture. It integrates a next-generation LMS API with an AI-driven runtime called the **SuA Agent**, which enables intelligent learning workflows, automated material parsing, assessments, and AI tutoring. 

**Project Presentation:** [Google Slides](https://docs.google.com/presentation/d/1i-CjZo40rBzzUsIeICv6SMBOxf-tL620/edit?usp=drive_link&ouid=112747811498918866655&rtpof=true&sd=true)

## ✨ Features

- **🎓 Comprehensive LMS System:** Course, class, enrollment, and lesson lifecycle management.
- **🤖 SuA Agent AI Runtime:** Orchestration, planners, reasoners, and tool calling via a Python-based AI service.
- **📚 Smart Material Ingestion:** Automated document parsing, chunking, embedding, and Retrieval-Augmented Generation (RAG).
- **📝 Intelligent Assessments & Roadmaps:** Auto-grading, mastery analysis, and personalized roadmap generation.
- **💬 Real-time Chat:** Interactive chat generated by AI tutors, supporting SSE (Server-Sent Events) for token streaming.
- **🔐 Secure Access:** Clerk authentication and route-level authorization enforced by the API Gateway.
- **⚡ Microservices Architecture:** Independent deployable services (API Gateway, BE Core, AI Service) scaling robustly.

## 🏗 Architecture

Our system is structured into three primary deployable services:

1. **API Gateway (NestJS):** The public HTTP ingress. It enforces authentication, rate-limiting, and proxies streaming AI responses.
2. **BE Core (NestJS):** The system of record. Owns the domain persistence (Prisma + PostgreSQL) and exposes internal gRPC services.
3. **AI Service (Python FastAPI):** The SuA Agent runtime. Handles orchestrator execution, RAG over Qdrant, prompts, and LLM provider interactions.

For detailed architecture diagrams and design, refer to the [System Architecture Document](./docs/system-architechture.md) and the [Architecture Diagram](./docs/architechture.webp).

## 🛠 Tech Stack

- **Monorepo:** [Nx](https://nx.dev/)
- **Frontend / Web:** React 19, Vite, TailwindCSS, Zustand, Framer Motion
- **API Gateway & Backend Core:** NestJS 11, TypeScript 5.9
- **AI Service:** Python 3.14, FastAPI, LangGraph (Orchestrator)
- **Database (OLTP):** PostgreSQL (managed via Prisma 7 ORM)
- **Vector Database:** Qdrant (for RAG and embeddings)
- **Caching & Queues:** Redis, RabbitMQ
- **Authentication:** Clerk
- **Storage:** Cloudinary / Object Storage
- **Internal RPC:** gRPC + Protobuf

## 🚀 Getting Started

### Prerequisites
- Node.js 20+
- Python 3.14 (for AI Service)
- Docker & Docker Compose
- Nx CLI

### 1. Start Infrastructure Services
To run the required local dependencies (PostgreSQL, Redis, RabbitMQ, Qdrant):
```sh
npm run compose:infra:up
```

### 2. Prepare the Database
```sh
npm install
npm run prisma:generate
npm run prisma:migrate
```

### 3. Build & Run Application Services
You can run the full container stack (API Gateway & Backend) using Docker:
```sh
npm exec nx run-many -t build -p backend api-gateway
npm run compose:app:up
```

Alternatively, run them locally via Nx:
```sh
# Run Backend Core
npm run backend:serve

# Run API Gateway
npm run gateway:serve
```

### 4. Stop the Services
```sh
npm run compose:down
```
